# Beginner Explanation Guide

The default answer style is engineering-location-first plus a short beginner explanation.

## Good Explanation

- Explain why a document matters.
- Define one or two terms only when needed.
- Tie the explanation to the user's current task.
- Keep it short.

Example:

```text
Beginner explanation: The schematic tells us which MCU pins are physically connected, but it does not decide which alternate function those pins use. For that, we need the port/pin-mux table in the chip manual or Excel attachment.
```

## Avoid

- Long textbook explanations.
- Unverified configuration advice.
- Explaining basic concepts that are not needed for the task.
- Replacing evidence with intuition.
